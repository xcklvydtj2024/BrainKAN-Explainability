# Primary Empirical Support Analysis & Benchmark Index

## Directory Contents

This directory contains the active empirical node-support distribution audit on real HCP fMRI functional connectomes:

- **`node_support_overlap_stats.csv`**: Full empirical support audit across all 48 cortical ROIs (240 directed functional edges). 
  - Details per-ROI min/max empirical quantiles for 0-Back and 2-Back conditions.
  - Documents condition support overlap: mean Jaccard overlap of $38.52\% \pm 5.08\%$ (covering $43.47\%$ of pooled quantile span).
  - Generated by `experiments/compute_support_overlap_empirical.py`.
  - Audited in `docs/critical_methodological_defense_and_bounds.md` (Section 3).
