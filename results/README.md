# Results Directory

This folder contains the output data and generated figures from the BrainKAN pipeline scripts.

When running scripts like `01_q1_q2_q3a_naive_analysis.py` or `03_synthetic_identifiability_benchmark.py`, all generated `.png` plots and `.csv` matrices will be saved here automatically.

See `manifest.json` for details on the environment and git commit used to generate these artifacts.
