\textbf{\large 1. Research Motivation \& Core Methodological Problem}\\[1pt]
In graph neural networks for functional neuroimaging, Kolmogorov--Arnold Networks (KANs) replace linear edge weights with learnable univariate B-splines $\Phi_{ij}(x) = \sum_{p} c_{ij,p} B_p(x)$, allowing direct visual inspection of edge-level transformations. In literature, researchers often interpret learned spline curvatures as evidence of in-vivo biological computation or task-specific cognitive mechanisms.

\textbf{The Foundational Methodological Problem:}
\textit{Do learned spline nonlinearities reflect task-specific information, or are they mathematical artifacts of operational metric definitions, evaluation domains, and non-convex optimization randomness?}
We identify two primary unmodeled confounding factors:
\begin{enumerate}\itemsep -2pt
    \item \textbf{Reference-Domain Shifts:} Measuring curvature across shifted input supports creates apparent nonlinearity jumps purely from grid boundary extrapolation rather than model differences.
    \item \textbf{Optimization Stochasticity:} Single initialization seeds can easily produce statistically significant conditional curvature differences that vanish or reverse across the broader optimization landscape.
\end{enumerate}

\textbf{\large 2. Model Architecture: BrainKAN Edge-Spline Parameterization}\\[1pt]
The benchmark evaluates a specialized 2-layer Graph Kolmogorov--Arnold Network tailored for functional connectomes:
\begin{itemize}\itemsep -2pt
    \item \textbf{Layer 1 (Learnable Edge B-Splines):} For each directed functional edge $e = (u, v) \in \mathcal{E}$, message passing computes:
    $\Phi_e(x_u) = w_{\mathrm{base}, e} \cdot \operatorname{SiLU}(x_u) + \sum_{k=1}^{G+k_o} c_{e, k} B_{k, k_o}(x_u)$,
    where $B_{k, k_o}$ denotes cubic B-spline basis functions ($k_o = 3$) parameterized over $G = 5$ grid intervals ($G+k_o = 8$ basis functions).
    \item \textbf{Exact Parameter Accounting:} For $|E| = 240$ edges, $C_{\mathrm{in}} = 1$, and $C_{\mathrm{out}} = 16$:
    \begin{itemize}\itemsep -2pt
        \item Spline coefficients: $240 \times 16 \times 1 \times 8 = \mathbf{30,720}$ parameters.
        \item Base residual weights: $240 \times 16 \times 1 = \mathbf{3,840}$ parameters.
        \item Root self-connections: $16 \times 1 = \mathbf{16}$ parameters.
        \item \textbf{Layer 1 Total:} $\mathbf{34,576}$ parameters. The complete 2-layer BrainKAN model contains $P = \mathbf{589,779}$ parameters.
    \end{itemize}
    \item \textbf{Operational Metric (Deviation-From-Linearity, DFL):} For any learned function $f$ evaluated on discrete grid $D = \{t_1, \dots, t_K\}$, DFL measures normalized variance unexplained by ordinary least-squares affine regression:
    \begin{equation*}
        \operatorname{DFL}(f; D) = \frac{\inf_{a, b} \sum_{k=1}^K |f(t_k) - (at_k + b)|^2}{\sum_{k=1}^K |f(t_k) - \bar{f}|^2} = \frac{\mathrm{SS}_{\mathrm{res}}}{\mathrm{SS}_{\mathrm{tot}}} = 1 - R^2
    \end{equation*}
\end{itemize}

\textbf{\large 3. Dataset, Pairing Manifest, and Cross-Validation Integrity}\\[1pt]
\begin{itemize}\itemsep -2pt
    \item \textbf{Primary Cohort (HCP-WM):} 100 healthy young adults from the Human Connectome Project 3T Working Memory task-fMRI. Contrast: 2-Back (high cognitive load) vs. 0-Back (low cognitive load), comprising 200 total graphs (100 strictly paired observations).
    \item \textbf{Brain Graph Topology:} 48 cortical Regions of Interest (ROIs), 240 directed functional edges ($|E| = 240$).
    \item \textbf{Cross-Validation Integrity:} 5-fold CV with strict subject-level pairing (\nolinkurl{data/subject_pairing_manifest.csv}). 0-Back and 2-Back scans for the same subject never cross fold boundaries. Fold reference grids $\mathcal{R}_k$ are computed exclusively from training subjects (zero train-test leakage).
    \item \textbf{External Cohort (CHCP):} Chinese Human Connectome Project dataset utilized for cross-cohort transportability checks.
\end{itemize}

\textbf{\large 4. Core Experimental Design: Progressive Falsification Suite}\\[1pt]
The benchmark evaluates 5 pre-committed experiments crossing input shifts with design-consistent null models:
\begin{itemize}\itemsep -2pt
    \item \textbf{Exp 1 (High-Precision Permutation Baseline):} Evaluates single-seed (\texttt{seed=42}) excess curvature on whole-graph average DFL over $N = 500$ sign-flip label permutations on $\mathcal{S}_{\mathrm{pooled}}$ ($\Delta = +0.00162, p = 0.0060$). This global-graph test is distinct from the edge-level FDR test in exploratory Q3B (where 0/240 edges reached significance).
    \item \textbf{Exp 2 (Synthetic Ground-Truth Calibration):} 3-condition controlled simulation ($N = 200$) on known function $f^*(x) = x + 0.5\sin(2x)$ assessing DFL sensitivity to uniform, domain-shifted, and density-weighted grids.
    \item \textbf{Exp 3 (Reference Domain Control):} 5-fold CV on fMRI data contrasting pooled ranges against empirical common support $\mathcal{S}_{\mathrm{common}} = \operatorname{supp}(X_0) \cap \operatorname{supp}(X_1)$ to eliminate boundary extrapolation.
    \item \textbf{Exp 4 (Capacity Sensitivity Analysis):} Multi-seed capacity sensitivity scan across BrainKAN hidden dimensions ($d \in \{4, 8, 16\}$ across 5 random initializations), with model parameter counts reported separately.
    \item \textbf{Exp 5 (Seed-Marginalized Permutation Testing, SMPT):} Multi-seed evaluation across $S = 10$ seeds $\times$ $B = 15$ permutations under \textbf{dual estimands}: (1) Pooled Support $\mathcal{S}_{\mathrm{pooled}} = Q_{1\%-99\%}([X_0, X_1])$; (2) Strict Common Support $\mathcal{S}_{\mathrm{common}} = \operatorname{supp}(X_0) \cap \operatorname{supp}(X_1)$.
\end{itemize}

\textbf{\large 6. Inferential Limitations \& Methodological Boundary Conditions}\\[1pt]
To preserve rigorous scientific integrity, our findings are bounded by explicit inferential commitments:
\begin{enumerate}\itemsep -2pt
    \item \textbf{Optimization Sensitivity vs. Population Generalization:} Exp 5 evaluates $S = 10$ optimization initializations on a fixed cohort. It demonstrates \textbf{initialization consistency}, not population-level generalizability across unseen patient cohorts.
    \item \textbf{Operational Residual Ratio vs. Differential Geometry:} $\mathrm{DFL} = 1 - R^2$ is an operational metric of unexplained variance against affine regression over a discrete grid, \textbf{not} an intrinsic coordinate-invariant Riemannian curvature tensor.
    \item \textbf{Finite Permutation Precision ($B=15$):} The 10 seeds share the same 15 permutation flip vectors ($\mathrm{SE}_{\mathrm{MC}} \approx 0.00015$). Exp 1 provides a high-precision single-seed anchor ($B=500, p=0.0060$).
    \item \textbf{Representation Inspection vs. Held-Out Generalization:} DFL inspects internal parameter geometry, not held-out classification accuracy. 5-fold CV functions as a subset sensitivity check.
    \item \textbf{Empirical Fallback Numerical Guard Audit:} The common support guard (\texttt{if c\_min >= c\_max:}) was audited across all 5 folds $\times$ 48 ROIs ($240$ instances): \textbf{$0 / 240$ triggered ($0.00\%$)}. All reported values reflect genuine non-empty overlaps.
\end{enumerate}
